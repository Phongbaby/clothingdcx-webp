# clothingdcx-webp

Ảnh quần áo cho server FiveM, bản nhẹ của kho `clothingdcx`.

- Chuyển từ PNG 512px sang WebP 256px (giữ nền trong suốt), giữ nguyên tên file, chỉ đổi đuôi `.png` → `.webp`.
- 8.787 ảnh, 963 MB → 66,6 MB.
- Link: `https://raw.githubusercontent.com/nkocvotam12/clothingdcx-webp/main/<tên>.webp`
